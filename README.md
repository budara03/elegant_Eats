# ELEGANT EATS

A modern full-stack web application for a custom cake business, allowing customers to browse cakes, design custom cakes, and place orders online with a seamless user experience.

---

## 📖 About the Project

**Elegant Eats** is a bakery management and custom cake ordering platform built using the **MERN Stack**. The application enables customers to explore cake collections, customize cakes for special occasions, and manage orders through an intuitive interface.

This project is currently under active development.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/eat-my-cake.git
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

### Backend

```bash
cd Backend
npm install
npm run dev
```
